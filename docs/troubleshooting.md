# 문제 해결

먼저 Vercel 주소 `https://<project>.vercel.app/api/reply`를 브라우저에서 여세요. 비밀값 없이도 `ok`가 보이는 것이 정상입니다. 그다음 MacroDroid 시스템 로그에서 `soopbot_status`와 `soopbot_reply`를 확인하면 문제 범위를 빠르게 좁힐 수 있습니다.

## 상태 코드별 확인

| 상태/증상 | 뜻 | 확인할 것 |
| --- | --- | --- |
| `200` + 답변 | 정상 처리 | Notification Reply가 실행되지 않으면 `soopbot_reply` 저장 변수, If 조건, **Use Notification Trigger**를 확인 |
| `204` + 빈 본문 | 답할 요청이 아님 | 호출어 불일치, URL의 `room`과 `SOOPBOT_ROOM_KEY` 불일치, 같은 알림 중복 전송 여부 확인 |
| `400` | 요청 형식이 잘못됨 | POST인지, 본문이 비어 있지 않은지, Content Type이 `text/plain; charset=utf-8`인지 확인. 너무 긴 알림도 줄여서 재시도 |
| `401` | 토큰 불일치 | `X-Bot-Token` 철자와 값이 Vercel의 `SOOPBOT_TOKEN`과 완전히 같은지 확인. 따옴표·앞뒤 공백을 제거하고 Vercel 재배포 |
| `429` | 분당 요청 한도 초과 | `Retry-After` 기준 60초 기다린 뒤 한 번만 재시도. 재귀 호출과 중복 트리거를 먼저 차단 |
| `503` | 서버 초기화 또는 내부 처리 실패 | Vercel 환경변수, 함수 로그, 최근 배포 상태 확인. 수정 뒤 재배포하고 잠시 후 다시 호출 |
| 상태가 `0`이거나 없음 | HTTP 동작이 완료되지 않음 | 인터넷 연결, Vercel URL, 60초 Timeout, 응답 상태 저장 변수, **Block next action until complete** 확인 |

OpenAI 호출 자체가 실패하면 HTTP `200`과 함께 `지금은 답변을 만들지 못했어요`라는 안전한 안내가 올 수도 있습니다. 이때는 OpenAI API 키의 유효성, API 결제/크레딧, 선택한 모델의 사용 가능 여부를 확인합니다. ChatGPT 구독 상태와 API 결제 상태는 별개입니다.

## 아무 반응이 없을 때

다음 순서로 한 항목씩 확인합니다.

1. MacroDroid의 숲봇 매크로가 활성화되어 있는지 확인합니다.
2. 공폰의 **설정 → 알림 접근**에서 MacroDroid가 허용되어 있는지 확인합니다.
3. 카카오톡 알림이 공폰에 실제로 나타나는지 확인합니다. 해당 방 알림을 꺼 두었다면 트리거가 동작하지 않습니다.
4. 트리거의 카카오톡 앱, 정확한 방 제목, `숲봇아` 포함 조건을 확인합니다.
5. HTTP 동작 앞에서 `soopbot_reply`를 비우고 `soopbot_status=0`으로 만드는지 확인합니다.
6. HTTP 동작의 완료 차단 옵션과 60초 제한 시간을 확인합니다.
7. Vercel 함수 로그에서 요청 시간대의 상태를 확인합니다. 로그에 질문이나 토큰을 직접 출력하는 코드는 추가하지 마세요.
8. 제조사 배터리 최적화에서 MacroDroid를 제외하고 다시 테스트합니다.

## 답장이 반복될 때

- Notification Received 트리거에서 봇 계정 자신의 카카오톡 이름/알림을 제외합니다.
- 대상 앱을 카카오톡으로, 방 제목을 정확한 한 방으로 제한합니다.
- MacroDroid의 중복 트리거 방지 옵션을 사용할 수 있으면 함께 켭니다.
- 실패 시 받은 서버 문구를 새 카카오톡 메시지로 보내는 Else 동작을 만들지 않습니다.

서버도 짧은 시간 동안 같은 요청을 중복으로 처리하지 않지만, 서버리스 인스턴스가 바뀌면 임시 중복 기록이 공유되지 않을 수 있습니다. 공폰의 자기 발신자 제외가 기본 방어입니다.

## Timeout 또는 늦은 답장

- 공폰에서 브라우저로 Vercel 상태 주소가 열리는지 확인합니다.
- MacroDroid HTTP Timeout은 60초, 서버의 `SOOPBOT_TIMEOUT_SECONDS`는 60초보다 짧게 유지합니다.
- OpenAI 상태와 Vercel 배포 상태를 확인하고, 긴 질문은 줄여 다시 시도합니다.
- 연속 재시도 매크로는 만들지 마세요. 비용과 중복 답장이 늘 수 있습니다.

## API 키나 토큰을 노출했을 때

노출된 값은 삭제만 하지 말고 즉시 폐기·교체해야 합니다.

1. OpenAI 대시보드에서 노출된 API 키를 폐기하고 새 키를 만듭니다.
2. Vercel 환경변수에서 노출된 `OPENAI_API_KEY` 값을 제거하고 새 키로 교체한 뒤 다시 배포합니다.
3. 예측하기 어려운 새 `SOOPBOT_TOKEN`을 만들고, Vercel에서 노출된 기존 값을 제거·교체한 뒤 다시 배포합니다.
4. MacroDroid `X-Bot-Token` 헤더 값도 새 토큰으로 바꿉니다.
5. 공개 Git 커밋이나 캡처에 값이 들어갔다면 현재 파일에서 지우는 것만으로 충분하지 않습니다. 노출된 값은 계속 폐기 상태로 두고 공개 기록의 정리는 플랫폼 지침에 따라 별도로 처리합니다.

저장소 자체의 보안 취약점은 공개 이슈에 비밀값을 붙이지 말고 [보안 정책](../SECURITY.md)에 따라 비공개로 알려 주세요.
